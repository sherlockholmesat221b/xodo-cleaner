Working with a very large PDF?

The browser tool above holds the whole file in memory, which is fine up to roughly 50–80 MB on most devices. For bigger files — or batches of them — use the companion Python script instead:

pip install pikepdf
python3 clean_xodo_watermark.py input.pdf
python3 clean_xodo_watermark.py *.pdf   # batch

It uses pikepdf (a C++ PDF library), applies the same checks as this page, and rebuilds the file afterward so leftover empty objects don't bloat the output — the result is usually a little smaller than the watermarked input.

What exactly gets removed

Each step only acts on something Xodo itself marks as watermark-related — nothing is matched by guesswork, so your own annotations, stamps, and links are never at risk:

  1. Restores each page's true size from a marker Xodo stores before expanding the page for the watermark band, cropping it out of view.
  2. Empties the one overlay object tagged with an Optional Content Group literally named "Watermark".
  3. Removes the one link annotation Xodo self-tags via /TrnCustomData.
  4. Strips the /PDFTRON metadata tag and the /xodo_watermark catalog flag the app reads to show its own "contains watermark" warning.
Nothing you upload here is sent anywhere — the PDF is parsed and rewritten entirely in your browser tab.
